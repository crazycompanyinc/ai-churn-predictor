# AI Churn Predictor for SaaS

**Micro-SaaS**: Predict which customers will churn before they leave.

## The Problem
SaaS companies lose 5-8% of customers monthly to churn. Most don't realize a customer is about to leave until it's too late. Existing solutions (ProfitWell, Churnly) are expensive and complex.

## The Solution
A lightweight AI tool that:
- Connects to your Stripe/Braintree via API
- Analyzes usage patterns, payment history, support tickets
- Scores each customer's churn risk (0-100)
- Sends alerts when high-risk customers are detected
- Recommends retention actions
